# Contributing

## Rule Contribution Requirements

Every Snort rule contribution should include:

- Detection objective
- Rule category
- Test traffic or PCAP reference
- False positive notes
- Response guidance
- `sid`
- `rev`
- `classtype`
- Metadata

## SID Ranges

| Range | Category |
|---|---|
| 1000000-1000099 | Local lab |
| 1000100-1000199 | Web |
| 1000200-1000299 | Malware |
| 1000300-1000399 | Recon |
| 1000400-1000499 | Policy |
| 1000500-1000599 | ICS |
