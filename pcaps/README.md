# PCAP Files

Place test PCAP files in this folder.

Recommended naming convention:

```text
scenario-description-yyyy-mm-dd.pcap
```

Examples:

```text
http-sqlmap-user-agent-2026-06-23.pcap
nmap-syn-scan-2026-06-23.pcap
malware-c2-gate-uri-2026-06-23.pcap
```

Do not commit sensitive production packet captures to a public repository.
